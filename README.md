## Uma Skill, transporte existente

A Skill está em [skill/motor-universal-linux/](skill/motor-universal-linux/); ações e fornecedores vêm do catálogo [engine/catalog.json](engine/catalog.json). O transporte usa o workflow existente de `martaxi-boss/VPS`, GitHub Actions e SSH, sem coordenador na VPS. O validador está pinado em `0b50e1d403deff8f3ccb421edd0b41c397d66b9b`, mas executa a release privada `current` ([Skill #42263667753](https://github.com/martaxi-boss/VPS/actions/runs/42263667753) PASS). Não alterar pin ou SSH por divergência de SHA.

O contrato para pedido e resultado está em [references/github-bridge.md](skill/motor-universal-linux/references/github-bridge.md). Inventário, ações tipadas, seleção automática, planos e REA MCP são suportados, mas cada nova capacidade requer testes GitHub, VPS e ZIP reais.

**Pendências concretas:** verificar consumidores e funções antes de decidir sobre os **oito pacotes APT globais restantes**; conciliar outras releases sem reset/deploy cruzado; verificar instalação real da Skill atual no ChatGPT (ZIP de CI não atualiza automaticamente). Quotas rígidas universais CPU/RAM e agentes Ruflo autónomos continuam não certificados. [PR #43](https://github.com/martaxi-boss/skill-universal/pull/43) é independente.

**Segurança:** não incluir segredos, ficheiros privados ou dados pessoais em repositórios públicos; base64 não cifra. Nenhuma instalação fora da pasta Ferrari, nenhuma alteração silenciosa à ponte SSH e nenhuma nova Skill paralela.
