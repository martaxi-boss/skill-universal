## Uma Skill, transporte existente

A Skill está em [skill/motor-universal-linux/](skill/motor-universal-linux/); o motor em engine/ e instaladores em install/. O transporte é o workflow Ferrari existente de martaxi-boss/VPS, por GitHub Actions e SSH, sem coordenador na VPS. O validador Ferrari foi atualizado para o SHA **`f1f3b03525adec7018d7d629243e7b0fbb7f5087`**, após testes reais. O antigo `292aeb7d` é histórico. O SSH, o workflow de transporte e os restantes projetos mantiveram-se inalterados.

O contrato para pedido e resultado está em [references/github-bridge.md](skill/motor-universal-linux/references/github-bridge.md). Inventário, ações tipadas, seleção automática, planos e REA MCP são suportados, mas cada nova capacidade requer testes GitHub, VPS e ZIP reais.

**Pendências concretas:** verificar separadamente a versão instalada da Skill no cliente ChatGPT (o ZIP gerado em CI não atualiza automaticamente a instalação); limites rígidos CPU/RAM e agentes Ruflo com modelos não certificados; migrar os oito programas APT globais restantes para o Ferrari e concluir a reconciliação das releases por projeto. A [PR #43](https://github.com/martaxi-boss/skill-universal/pull/43) permanece assunto independente e só deve ser reavaliada com provas próprias.

**Segurança:** não incluir segredos, ficheiros privados ou dados pessoais em repositórios públicos; base64 não cifra. Nenhuma instalação fora da pasta Ferrari, nenhuma alteração silenciosa à ponte SSH e nenhuma nova Skill paralela.
